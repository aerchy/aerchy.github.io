### Service Discovery Analysis

The Nmap scan reveals a Windows machine running Microsoft IIS 10.0 on port 80. This is a classic Windows Server environment with a web server hosting the pov.htb domain. The presence of the TRACE HTTP method indicates potential security misconfigurations that could be exploited for information disclosure.

### Port 80 - HTTP Service Enumeration

Upon accessing the web application, we enumerate the available pages and functionality to identify potential attack vectors.

**Discovery of Subdomain and User Information:**

Through manual exploration of the application, specifically the Contact Us page, we discover critical information:

- **Subdomain discovered:** `dev.pov.htb`
- **User identified:** `sfitz` (mentioned in contact information)

This subdomain and username become key components in the exploitation chain. The dev subdomain likely hosts development-version applications with potentially weaker security controls.

## **User**

### Local File Inclusion (LFI) via CV Download

The **dev.pov.htb** subdomain contains a CV download feature. By intercepting the HTTP request with Burp Suite and modifying the requested file parameter, we can read sensitive system files instead of the intended CV document.

#### Step 1: Intercept Download Request

Access the **dev.pov.htb** application and locate the download CV button. Intercept the HTTP request using Burp Suite.

![](/assets/img/pov/Pasted_image_20260915142343.png)


#### Step 2: Modify File Parameter

Instead of requesting `cv.pdf`, we modify the request to target `web.config`, which is a critical IIS configuration file containing sensitive information.

![](/assets/img/pov/Pasted_image_20260912062042.png)

![](/assets/img/pov/Pasted_image_20260912062114.png)

On the attacker's machine, set up an HTTP server to serve the reverse shell script and a Netcat listener to receive the reverse connection.

Return to Burp Suite and intercept the CV download request again. Replace the VIEWSTATE parameter with the base64-encoded malicious token generated by ysoserial.

#### Step 5: Remote Code Execution Achieved

Upon sending the modified request, the ASP.NET application deserializes the malicious ViewState token, triggering the gadget chain that executes our PowerShell payload. The target system connects back to our listener, establishing a reverse shell.

We now have code execution on the target system running as the IIS application pool user.

## **Root**

### Process Migration for Privilege Escalation

The alaading user possesses the SeDebugPrivilege, which allows debugging of processes. By migrating our Meterpreter process to a system-level process (Winlogon.exe), we elevate our privileges to SYSTEM.

#### Step 1: Check Current Privileges

Verify the privileges available to the current user.

```powershell
whoami /priv

Privilege Name                Description                    State
============================= ============================== ========              
SeDebugPrivilege              Debug programs                 Disabled              
SeChangeNotifyPrivilege       Bypass traverse checking       Enabled               
SeIncreaseWorkingSetPrivilege Increase a process working set Disabled
```

Although SeDebugPrivilege appears disabled, Meterpreter can enable it during migration.

#### Step 2: Enumerate Running Processes

List all running processes to identify Winlogon.exe, which runs with SYSTEM privileges.

```powershell
meterpreter > ps
```

![](/assets/img/pov/Pasted_image_20260912080836.png)

**Winlogon.exe identified with PID 552 running as SYSTEM.**

#### Step 3: Migrate Meterpreter Process

Perform a process migration from the current process to Winlogon.exe (PID 552) to assume SYSTEM privileges.

```bash
meterpreter > migrate 552
```

![](/assets/img/pov/Pasted_image_20260912080941.png)

**Full SYSTEM privileges have been achieved. The attacker now has complete control over the target system.**

### Attack Chain Summary

1. **Reconnaissance:** Identified IIS 10.0 running on Windows via Nmap and discovered dev.pov.htb subdomain and sfitz user
2. **Initial Access:** Exploited Local File Inclusion to read web.config and extract encryption keys
3. **Code Execution:** Leveraged Insecure Deserialization via malicious ViewState tokens using TypeConfuseDelegate gadget chain
4. **Lateral Movement:** Extracted credentials from connection.xml and moved laterally to alaading user
5. **Privilege Escalation:** Utilized SeDebugPrivilege to migrate Meterpreter process to Winlogon.exe and achieve SYSTEM privileges
6. **Full Compromise:** Complete system domination with SYSTEM-level access
